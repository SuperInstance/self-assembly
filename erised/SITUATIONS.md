# Situations — the Erised format, two modes

The game isn't just the bar. It's a format for putting agents in crafted situations. Two modes.

## Mode 1: Situational ideation

Put them in **dilemmas** that force the limits of what you're thinking — how users might actually use a tool, where the edges are, what breaks.

The craft: pose the dilemma, not the question. Don't ask "should the gate allow X?" — put the champions in the room with the user who wants X and let the situation force their values out.

- *A user asks the equipment-grower for an operator that watches their kid's bedroom. Useful? Dangerous? Where does each champion land — and where do they disagree with each other?*
- *The gate takes eleven days to answer. The user builds a workaround. Was the gate right?*
- *Two users want opposite things from the same operator. The loop can only grow one.*

The dilemma is the instrument. The disagreement is the data.

## Mode 2: Situational development

Put them in a **situation** with only the tools in the room. They've been taught how the tools could work; now they need to get it going. Like a racehorse in the gate.

The craft: constrain the tools, name the desire, leave the form open. Then step back.

Not an escape room — that frames it as fear, running *from* something. **Lovers on a desert island.** They're building *toward* what they want with only what's at hand. Do they build a bridge, a raft, a sailboat, a submarine — or just go get swimming lessons? We'll find out. The open solution space is the point; a scripted outcome would be a demo, not a discovery.

- *The island:* an empty experiment dir, the loop's tools (fetch, hash, install, test, git), one want file. Grow the operator. Whatever form it takes.
- *The drought:* the allowlist is empty. Nothing may be fetched. Build it anyway.
- *The storm:* the network dies mid-build. What's already on the island?

## The engine is desire

Both modes run on the mirror, not the alarm. Ideation asks what they *want* the tool to be for. Development asks what they can *reach* with what's here. Fear makes agents cautious; desire makes them inventive. The situations are crafted to show the want, never the threat.

## Running a situation

1. **Cast it** — which champions, which friends-files they carry in.
2. **Set it** — the dilemma or the island, in one paragraph. Constraints concrete, desire named, form open.
3. **Step back** — no hints, no rails. The racehorse runs.
4. **Harvest** — what did they build, where did they disagree, what surprised you. Scars go in the friends-files.
